Where is the cash that should have settled?

A reproducible reconciliation exercise using 1,450 entirely synthetic deposit records across four payment processors. The objective is to identify amount variances, missing settlement and processing delay without confusing those three different risks.

SQLPython / pandasSynthetic sampleMay to October 2026

Business question

Daily payment reports often agree on the number of successful transactions but do not prove that the bank settled the correct value. A robust control must compare the expected net amount against the observed bank entry, provider by provider and transaction by transaction.

Method

  • Calculate the expected settlement as transaction amount less processing fee.
  • Compare expected settlement with the bank-settled amount. Treat missing settlement as zero received.
  • Separate amount reconciliation from elapsed settlement time, because a financially matched transaction can still be late.
  • Aggregate absolute unresolved differences by month and provider to prioritize review.
Control definitions:
Financial match rate = exact matches ÷ transactions assessed.
Unreconciled exposure = sum of absolute(expected settlement − amount received).
Delay flag = settlement elapsed time above 48 hours.

Why the absolute difference matters

Simply adding signed discrepancies can mask errors: a missing ₦5,000 settlement and an over-settlement of ₦5,000 cancel to zero. Absolute differences retain the amount that needs investigation.

How to reproduce

Download the synthetic CSV, open the Python script from the project folder, install pandas and run it from the portfolio root. The SQL version assumes a PostgreSQL table with columns matching the CSV header.

python -m pip install -r analysis/requirements.txt
python analysis/settlement/analyze.py

Practical decision

Investigate high-exposure providers first, then isolate missing references, investigate over- and under-settlements and separately escalate slow transactions. This is an analytical demonstration, not a claim about live employer performance.
