## Reproduce the analysis

The repository includes runnable analysis scripts, Python dependency information, generated datasets and project-specific README files. From the repository root, install the dependencies and run any project:

```bash
python -m pip install -r projects/requirements.txt
python projects/fraud-intelligence/src/run.py
python projects/commission-profitability/src/run.py
python projects/cashflow-forecast/src/run.py
python projects/payment-reconciliation/src/run.py
python projects/process-efficiency/src/run.py
```

Each project documents its inputs, assumptions, calculated results and limitations in its own folder. The `projects/*/powerbi/` directories contain DAX and report-building instructions. **Native Power BI `.pbix` files are not included.**

The homepage also retains earlier interactive settlement and commission demonstrations, with supporting scripts in [`analysis/`](analysis/), synthetic inputs in [`data/`](data/) and supplementary pages in [`case-studies/`](case-studies/).

## Data integrity and limitations

All portfolio transactions, customer-like records, financial figures, fraud labels, commission scenarios and workflow events are **synthetic**. The published results are outputs of reproducible demonstrations, not actual client or company financial performance. No confidential company or customer data is published.

The fraud project evaluates artificial labels, not a production fraud model. Financial forecasts and incentive changes are scenario exercises, not predictions or verified operational outcomes. Power BI report specifications are provided, but published `.pbix` dashboards have not yet been built.
